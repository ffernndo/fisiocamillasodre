# Camilla Sodré — Fisioterapia Pélvica, Dermatofuncional e Saúde da Mulher

Site institucional de **Camilla Sodré**, fisioterapeuta especializada em fisioterapia pélvica, dermatofuncional, estética e saúde da mulher.

🌐 **Site no ar:** [fisiocamillasodre.com.br](https://fisiocamillasodre.com.br)
📸 **Instagram:** [@camisodre](https://instagram.com/camisodre)

## Estrutura

| Arquivo/pasta | Função |
|---|---|
| `index.html` | Página completa (landing page — HTML, estilos e seções) |
| `support.js` | Runtime dos Design Components (gerado automaticamente, não editar) |
| `assets/camilla/` | Fotos usadas nas seções do site |
| `CNAME` | Domínio personalizado do GitHub Pages |

## Publicação

- **Hospedagem:** GitHub Pages (branch `main`, raiz)
- **Domínio:** `fisiocamillasodre.com.br`, registrado no Registro.br
- **DNS:** zona no Registro.br — 4 registros `A` apontando para o GitHub Pages (`185.199.108–111.153`) e `CNAME www → ffernndo.github.io`

## Como atualizar o site

1. Edite o `index.html` (ou substitua fotos em `assets/camilla/`)
2. Commit e push na branch `main`
3. O GitHub Pages publica automaticamente em 1–2 minutos
